# 纸间 · 小说听读器

为私下分享小说而做的手机网页应用，优先适配 iPhone Safari，也支持电脑及安卓浏览器。网站与语音网关部署到公网后，日常使用不需要作者的电脑常开。妈妈在自己的手机导入普通文档，选择晓晓、晓伊、云希或云扬，首次同意在线生成后即可逐段收听；也可导入 `.zjbook` 听书包离线播放。书架、音频缓存和进度保存在本机。

**验证状态（2026-11-05）：**公网语音网关已部署，晓晓、晓伊、云希、云扬均使用自写中性短句完成线上真实合成验证，返回 `audio/mpeg`。直接播放界面已在本地 Edge 验证；真实 iPhone 的锁屏、后台和长时间续播仍待设备实测。

## 已实现

- 导入 `.md` / `.markdown` / `.txt` / Word `.docx`，可批量导入；单个文件上限 20 MB。
- 普通文档通过配置的 Cloudflare 语音网关逐段生成四种中文自然语音；先播放本机缓存，未缓存的段落需联网生成。首次使用需明确同意发送文字；仅导入、打开书籍或在暂停时切换段落和音色不会上传正文。
- 预生成四音色 .zjbook 听书包：晓晓、晓伊两种女声，云希、云扬两种男声；逐段 MP3，导入后可离线听，也可只生成其中几种节省空间。
- Markdown 标记清理、Word 段落和标题提取、章节目录、搜索和书架管理。
- 正文阅读、字号 16–32、宋体/黑体、行距和暖纸/护眼绿/夜间主题。
- 点击任意段落开始听，上一段/下一段、拖动进度、章节跳转、阅读和听书共用位置。
- 0.5–2 倍语速、固定四种中文自然音色、15/30/60 分钟定时停止；不读取手机系统声音列表。
- 自动保存正文、进度与偏好，支持添加主屏幕；HTTPS 下可缓存应用以离线打开。
- 内置两篇原创体验短篇，可自行移除。

首次部署需要一个 GitHub 账号：

1. 在 GitHub 创建一个**公开**的空仓库，例如“jian-reader”。不要勾选自动创建 README 或 .gitignore。

~~~powershell
git branch -M main
git remote add origin 'https://github.com/你的用户名/你的仓库名.git'
git add .github .gitignore README.md index.html package.json package-lock.json public scripts src tests
git commit -m 'Publish reader'
git push -u origin main
~~~

4. 在仓库“Actions”中等“Deploy reader to GitHub Pages”成功。正式地址显示在“Settings → Pages”，通常是 https://你的用户名.github.io/你的仓库名/ 。把这个地址发给妈妈，用 Safari 打开即可。“分享 → 添加到主屏幕”可像 App 一样使用。

## 在线自然语音服务

在线朗读的路径是：手机当前段落 → 自己部署的 Cloudflare Worker → Microsoft Edge 在线语音服务 → 手机播放并缓存音频。只提供晓晓、晓伊、云希、云扬四种固定中文音色，不识别手机系统声音，也不加载其他语言的声音。

网关部署说明见 [`worker/README.md`](worker/README.md)。已部署接口为 `https://zhijian-reader-voice.songyanghe123.workers.dev/v1/tts`，允许正式网页来源 `https://chihiro011012.github.io`。前端地址在 `src/online-config.js` 配置，也可以通过构建环境变量 `VITE_TTS_ENDPOINT` 指定完整的 `/v1/tts` 地址。换用自己的网关时，应同步检查允许的网页来源，并使用自写示例文字验证真实音频，再用手机试播。

Cloudflare 网关代码不保存小说正文或音频，也不把书架发布到 GitHub；正文会经过 Cloudflare，并交由 Microsoft Edge 在线语音服务处理。首次点播放会说明此过程并询问是否同意，之后连续朗读只发送需要生成的段落。可在听书设置中停止在线生成。不要将不能交给该服务的未发表内容用于在线朗读。

音频生成成功后按书籍、段落及音色缓存在本机，之后可直接播放已有缓存。暂停生成、跳转、切换音色或换书会取消当前请求；打开书籍、导入文件和暂停时浏览不会触发生成。未配置网关、网络异常或服务暂时不可用时会显示可重试的错误，不会要求普通文档必须先制作听书包。

网关可使用 Cloudflare Free 方案部署，但仍受该方案与上游服务的限制。Edge 语音是非官方接入，声音供应、免费使用规则、可访问性及稳定性可能变化；本项目不承诺永久免费、无限量或持续可用。音质并非真人录音。已导入的听书包不依赖在线网关。

## 可选：生成离线自然语音听书包

在作者的 Windows 电脑上安装 Node.js 22.18+ 和 Python 3，然后双击「scripts/生成听书包.cmd」。按提示把小说文件拖进窗口；首次运行会安装免费的 `edge-tts`。脚本默认生成女声“晓晓、晓伊”和男声“云希、云扬”，输出的 `.zjbook` 与原文档放在同一文件夹。把这个包私下发给妈妈即可；生成完后电脑可以关机，妈妈播放时不会再次调用语音服务。

也可以在 PowerShell 运行：

~~~powershell
node scripts/make-zjbook.mjs --input 'C:\小说\我的小说.md'
# 只生成晓晓女声以减小文件体积
node scripts/make-zjbook.mjs --input 'C:\小说\我的小说.md' --voices xiaoxiao
~~~

支持 `.md`、`.txt`、`.docx`。`--dry-run` 可以先检查段落数量而不联网。四音色听书包最多 300 MB；超过后请按卷拆分原稿，或使用 `--voices xiaoxiao` / `--voices yunxi` 生成单声包。一个原文档最多 20 MB。

**隐私与费用：**生成听书包时，作者电脑会把小说正文逐段发送到 Microsoft Edge 的在线语音服务；不要把不能交给该服务的未发表内容用于生成。手机播放包内已有音频时不会再次上传正文。`edge-tts` 是调用该在线服务的免费开源工具，属于非官方接入；声音供应、服务稳定性及使用规则可能变化。

## 给妈妈使用

1. 把收到的 Word / Markdown / TXT 文档或 `.zjbook` 听书包「存储到文件」。普通文档可直接在线生成语音，听书包则提供提前生成好的离线音频。
2. 用 Safari 打开纸间公网地址，点右上角「＋」导入文件。导入文件不会自动开始播放或上传正文；首次导入听书包时需要等待音频保存完成。
3. 点书架上的小说开始看；选好音色后点播放，也可轻点正文中的某一段从那里听。普通文档首次在线播放需点「同意并播放」，生成声音时可以点暂停取消。若浏览器提示音频已准备好，再点一次播放即可。
4. 到「听书」页面在晓晓、晓伊、云希、云扬中切换音色，或调整语速和定时；到「阅读设置」调字号。
5. 正式 HTTPS 网站可通过 Safari「分享 → 添加到主屏幕」安装。联网打开一次完成应用缓存后，可离线阅读；离线收听仅限已生成且保留在本机的音频，或已导入听书包内的音频。未生成的段落或另一种音色需要联网。先用飞行模式试播一小段确认。

旧版 `.doc` 需要先用 Word/WPS 另存为 `.docx` 或 TXT。图片扫描版 Word 没有可提取的文字，需先识别文字。导入只保留小说正文和标题，不保留 Word 排版、插图、批注或已删除的修订。

## iPhone 的实际边界

- .zjbook 包使用提前生成的 MP3，四种中文自然音色由包本身提供，手机无需安装额外声音；音频保存在本机。旧双音色包仍可播放，未生成的音色会显示不可用；重新生成四音色包即可全部使用。
- 普通 Word / Markdown / TXT 文档可直接阅读；在线朗读依赖手机网络、已配置的语音网关和上游服务。应用不调用浏览器 SpeechSynthesis，也不读取系统或其他语言的声音。
- 两种方式都使用浏览器音频播放；在线生成后的首次播放可能受浏览器自动播放限制，需要再点一次播放。锁屏、后台播放与跨段自动续播受 iOS 调度影响，仍需在真实 iPhone 上验证，不能保证长期连续播放。建议先保持页面前台试播。支持时会申请屏幕常亮。
- 普通文档可离线阅读；本机已有的在线音频缓存与听书包音频可离线播放。缓存清理后需重新联网生成或导入听书包。
- 阅读进度按段落保存。重新打开小说会从保存的段落开始；切换音色会从当前段落重新播放。
- 普通局域网 HTTP 地址可以试用，Service Worker 离线缓存需要 HTTPS 或 localhost。Safari 私密浏览、清除网站数据或设备清理可能删除书架，务必保留原始文档。

## 数据与地址

`npm run build` 生成 `dist/`，也可以将整个目录部署到其他支持 HTTPS 的静态网站托管（支持子目录）。不需要服务器数据库或读者账号；网站资源可以公开托管，小说仍由妈妈本地导入，不随网站发布。普通文档在线朗读使用独立的 Cloudflare Worker 网关；仅部署静态网页不会提供语音生成服务。

运行 `npm run build` 会生成安装图标与包含内容版本号的 Service Worker。应用静态资源放在离线缓存中；导入的小说与已生成音频放在 IndexedDB，不上传到 GitHub Pages。普通文档在线朗读在用户同意后把需要生成的段落发送到语音网关和上游服务；电脑生成听书包是另一项主动联网步骤。更换域名/协议/端口会形成不同的本地书架，文档和听书包需在新地址重新导入。请保留原稿和听书包备份，Safari 清理网站数据可能清空本机书架。

## 验证

`npm test` 使用 Node 内置测试，覆盖 Markdown/TXT/Word 内容与章节解析、听书包结构与错误文件拒绝、逐段播放和四音色切换、旧音色偏好迁移、本地设置，以及在线生成的缓存命中、取消请求、迟到结果、长文本完整分段和错误重试。在线客户端单元测试使用模拟服务，不上传用户原稿，也不能代替部署后的真实合成验证。2026-11-05 共 86 项测试通过；本机 Cloudflare workerd 网关使用自写中性文字实际合成了四种音色，1120 字长段落也成功返回音频。本地 Edge 网页使用内置原创体验短文验证了四音色直接播放、逐段续播、暂停，以及撤回在线生成同意后播放已有缓存、缓存缺失时重新询问同意。公网网关部署后，`/health` 返回四音色列表，正式网页来源的 CORS 正确，四种音色使用自写中性短句请求均返回 HTTP 200 和 `audio/mpeg`；这项验证确认线上合成服务可用，不代表正式网页或真实手机端已完成播放验证。构建命令验证生产资源可打包。尚未在真实 iPhone 设备上验证锁屏与长时间续播。

结构：`src/main.js` 界面与交互，`src/importer.js` 文档解析，`src/audio-package.js` 听书包解析，`src/audio-player.js` 音频播放，`src/online-tts.js` 在线语音客户端，`src/online-consent.js` 在线使用同意状态，`src/online-config.js` 默认网关地址，`src/voices.js` 固定四音色目录，`src/storage.js` 本地持久化，`worker/` 线上语音网关，`scripts/make-zjbook.mjs` 可选的离线听书包生成器。网页不使用远程字体或统计服务；在线朗读会连接配置的网关。
